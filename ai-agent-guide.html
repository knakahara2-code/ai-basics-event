AIエージェント 使い分け＆セットアップ

「同じ脳に、手が付いたもの」── いつ・どれを使い、どう立ち上げるか

チャット型AIは助言する（文章で返すだけ）。エージェント型AIは作業を終わらせる（実際にファイルを開き・作り・保存する）。 同じ脳（クラウド）に「手と机」を付けたのがエージェントです。合宿で実際に動かすのはこちら。まず全体像 → 使い分け → セットアップの順でいきましょう。

① まず一覧で「使い分け」

7つを、接点（使い方）と得意で並べました。太字が名前、色は提供元。

ツール接点（使い方）誰向け得意なことこんな時に
Claude CoworkAnthropic 会話・デスクトップアプリ
ターミナル不要		 非エンジニア フォルダ整理・Excel/PPT等の成果物・調査を"丸投げ" まず会話で任せてみたい。黒い画面は使いたくない
GensparkGenspark 会話・ブラウザ
インストール不要		 全員 1プロンプトで資料・サイト・動画・リサーチを量産（複数AIを束ねる） 成果物をとにかく早く出したい
Claude CodeAnthropic ターミナル／アプリ
CLI		 作る人・本格運用 コード・自動化・多段の自律作業の主力。Coworkと同じ基盤の"本気版" 本格的に作り込む・業務を自動化する
OpenAI CodexOpenAI ターミナル＋IDE＋クラウド
CLI		 ChatGPT派・開発寄り サンドボックスで安全にコード実行。サブエージェント並列 ChatGPT課金の範囲で開発したい
Gemini CLIGoogle ターミナル
CLI		 Google派・開発寄り 端末でGemini・100万トークン・MCP対応 ※無料枠は6/18にAntigravity CLIへ移行。有料API/Vertexは継続
Google AntigravityGoogle IDE／デスクトップ／CLI
開発基盤		 開発チーム 複数エージェントを並列で走らせる。実ブラウザを操作しながら作る 開発をエージェント主導で回したい
NotebookLMGoogle ブラウザ
インストール不要		 全員 アップした資料"だけ"に根拠を置く調査（引用付き）＋音声要約・スライド化 手持ち資料を読み込ませ、正確に調べ・まとめたい
迷ったら：会話で任せたい非エンジニア → Claude Cowork／本格的に作る → Claude Code／手持ち資料の調査 → NotebookLM。 Cowork と Claude Code は同じ脳・同じエージェント基盤で、接点が「会話」か「ターミナル」かの違いです。

② 立ち上げる（セットアップ手順）

合宿で実際に触る主力4つ。完走しなくてOK、まず一歩踏み出せれば成功です。

Claude Code

Anthropic ／ 本格的に作る・自動化する
  1. claude.com/download からネイティブ版をダウンロード
    （ネイティブ版は Node.js 不要・自動更新）
  2. インストール → 起動
  3. 有料アカウント（Pro / Max / Team など）でログイン
Mac / Windows / Linux 対応。無料plan では使えません。npm 版は旧経路（Node.js 22+）。

Claude Cowork

Anthropic ／ 会話でまるごと"任せる"（ターミナル不要）
  1. claude.ai/download から Claude Desktop を入れ、有料planでログイン
  2. メッセージ欄で Cowork を選択
  3. 「Work in a folder」で作業フォルダを指定 → 自然文で依頼 → 承認して実行
Claude Code と同じ基盤をアプリ化したもの。アプリを閉じても処理は継続（ローカルファイルを使う時は開いておく）。

OpenAI Codex

OpenAI ／ ChatGPT派のコーディングエージェント
  1. ChatGPT（Plus / Team など）アカウントを用意
  2. ターミナルで npm i -g @openai/codex
  3. codex を起動 → ChatGPTでログイン（モデル gpt-5-codex）
既定は Suggest モード（毎回承認）＋サンドボックス（ネット遮断・カレント配下のみ）。VS Code拡張やクラウド版（chatgpt.com/codex）も。

Gemini CLI

Google ／ 端末でGemini（開発寄り）
  1. ターミナルで npm i -g @google/gemini-cli
  2. gemini を起動 → Google / API で認証
  3. 設定は ~/.gemini/ に保存
※ 2026/6/18に無料ホスト版バックエンドを停止。無料で使うなら Antigravity CLI へ。有料API / Vertex は継続。

ブラウザで今すぐ（インストール不要）

Genspark — genspark.ai：無料200クレジット/日・カード不要で即開始
NotebookLM — notebooklm.google.com：資料をアップ→質問・音声要約
Google Antigravity — antigravity.google：DL（Free / Pro / Ultra）
安全に使うコツ：エージェントに見せたものは脳（クラウド）に送られます。ダミーデータで試す・「承認」を挟む・"学習しないプラン/設定"を選ぶの3つで、リスクは Gmail や freee にデータを預けるのと同程度に収まります。「AIだけ特別に怖がる」必要はありません。
